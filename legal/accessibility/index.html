Accessibility Statement

This site is built to be usable by everyone, including people using assistive technologies.

Last updated: November 22, 2026

Commitment

Syntheris Studios Inc. is working to make syntheris-studios.com accessible to people with disabilities, so that every visitor can browse the site with the same ease and enjoyment.

What has been done

The site is built with semantic HTML and a clear heading structure on every page. Images carry alternative text. Every link and control is reachable by keyboard. Text and background colours are chosen for readable contrast. The site contains no auto-playing video, audio, or animation, and its text resizes with the browser.

Standard

The aim is conformance with the Web Content Accessibility Guidelines (WCAG) 2.1, level AA.

Feedback

If you find an accessibility issue on the site, or need any content in another format, write to info@syntheris-studios.com and the studio will do its best to help.
