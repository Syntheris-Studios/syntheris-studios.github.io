Syntheris Continuum

Precision interpolation for AI-generated video. A local Windows application that generates intermediate frames to change a clip's frame rate — with duration preservation, fortified error handling, and research-oriented presets wrapped around RIFE v4.26.

Engine: RIFE v4.26 · Runtime: PyTorch 2.7.1+cu128 · Validation: 45 tests passed, 1 skipped.
